# API2 · API päringulabor

Interaktiivne eestikeelne õppesimulatsioon, mis aitab tudengil läbi teha Statistikaameti tabeli PA111 API-töövoo:

1. küsi GET-päringuga metaandmed;
2. vali näitaja, tegevusala ja vaatlusperiood;
3. koosta ja saada POST-päring;
4. vaata ning kontrolli saadud vastust.

## Tehnoloogia

Rakendus kasutab HTML5, CSS3 ja JavaScripti (ES2022). See ei vaja ehitussammu ega serveripoolset rakendust.

## Avalik aadress

GitHub Pages avaldab `dist/` kausta aadressile:

`https://siimkl.github.io/API2/`

## Kohalik käivitamine

```powershell
.\Start-Local.ps1
```

Seejärel ava brauseris skripti väljastatud kohalik aadress.
